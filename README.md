# 🎓 Student Planner - Student Performance & Activity Tracker

Student Planner is a web application developed as an exam project, designed for professors and homeroom teachers to effectively **track students' progress and independent study at home**. 

The system leverages the power of Object-Oriented Programming (OOP) in PHP and a MySQL database, paired with a modern, responsive, and aesthetically pleasing Bootstrap user interface.

---

## 🚀 Technologies Used

* **Backend:** PHP (Object-Oriented Programming - OOP)
* **Database:** MySQL 
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Frameworks & Libraries:** Bootstrap 5 (Responsive UI)
* **Local Development Environment:** XAMPP / phpMyAdmin

---

## 👥 Application Use Case & Features

The application is engineered as a **central administrative panel for teachers**. Its primary goal is to provide educators with a clear, visual, and statistical overview of students' academic activities outside the classroom:

* **Full CRUD Operations & Data Entry:** The professor can seamlessly log, view, and manage student records, including the subject, specific home-study topic, time spent learning (in minutes), and the grade achieved or assigned.
* **Global Analytics Dashboard:** Dynamic cards at the top of the page automatically calculate and display real-time metrics for the entire class (total number of active students, subjects covered, and total combined study hours).
* **Advanced Filtering System:** To facilitate individual consultations or analyze a specific student's performance, an advanced filter is integrated. Selecting a student from the dropdown instantly isolates their records in the table, while the analytics cards automatically recalculate study hours and statistics **exclusively for that student**.
* **Form Validation & Security:** Safe and validated data entry on the backend to prevent empty inputs or incorrect data types from corrupting the database.
